F12 TRACKING - WHICH REQUEST TO COPY FOR EACH LINE
==================================================

These lines block the app's server, so their data has to come from your own
browser. On each site you open the tracking page, search your number, and
copy one request from the F12 Network tab.

Lines the app reads by itself, with no F12 needed:
Yang Ming, COSCO, ONE, Arkas, First Flight.


HOW TO COPY A REQUEST
---------------------
1. Open the line's link below, press F12, go to the "Network" tab and click
   "Fetch/XHR".
2. Search your tracking number on the site.
3. Find the request named below. If you can't find it, press Ctrl+F inside
   the Network panel and type your tracking number. The panel shows which
   request contains it.
4. Click the request, open "Response", then right-click and choose
   "Copy response".
5. If Fetch/XHR shows nothing useful, click "All" instead. The data is then
   inside the page itself, so copy the page's main request.

WHAT TO SEND BACK
-----------------
For each line: the request's name and the copied response. A real tracking
number on its own is also enough. The app's paste box for that line is then
built from it, the same as the one MSC has.
